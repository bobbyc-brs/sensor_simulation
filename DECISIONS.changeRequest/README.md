# Change Requests — inbox for `Sensors`

One file per request, `CR-nnn-<slug>.md`; `**Status:**` in each file tracks its
lifecycle (Pending → Processed, or `Question pending (<owner>)`, or
`⚖ user's call`). Read newest first — sort by number, descending.

Requesters never edit this repo's other files; the owner applies each change in
this tree and records the commit ref in the CR. Protocol:
`~/Projects/standards/CHANGE-REQUESTS.md`. File with
`~/Projects/standards/devel-scripts/file-change-request.sh DECISIONS.changeRequest "<title>"`.
